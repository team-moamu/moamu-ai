# Notion 벤치마크 기록 초안

이 문서는 Notion에 만들 세 개의 표와 현재 평가 결과를 정리한 초안이다. 표는 각각 **모델 테스트**, **프롬프트 버전별 실험 기록**, **평가 데이터셋**을 관리한다. 모델 테스트 표는 한 행을 한 번의 평가 묶음으로 기록하고, 프롬프트·데이터셋 표와 관계형 속성으로 연결하는 구성을 권장한다.

현재 Gemini 파일럿은 조건 단위 지표다. 사진 제출 전체의 최종 승인율이나 PRD의 오승인율 목표를 입증한 결과로 해석하지 않는다.

v3은 영양제 사진 두 장만 사용한 집중 재시험이라 v2·v4의 30장 전체 평가와 정확도나 오승인율을 직접 비교하지 않는다. 비용은 Google Standard 토큰 단가로 계산한 추정치이며 실제 청구 내역이 아니다.

| 속성 | Notion 속성 유형 | 기록 내용 |
|---|---|---|
| 버전 ID | 제목 | 예: `photo-verification-v4` |
| 상태 | 선택 | 과거 버전, 기준선, 실험 중, 현재 기본값 등 |

| 변경 요약 | 텍스트 | 직전 버전에서 바꾼 한 가지와 바꾼 이유 |
| 프롬프트 원문 | 페이지 본문 | 재현용 고정 지침 전체. 코드에도 동일한 버전을 보존 |
| 평가 실행 | 관계형 | 모델 테스트 표의 평가 행과 연결 |

### 현재까지의 버전 기록

| 버전 ID | 상태 | 조건 전달 형식 | 변경 요약 | 평가 결과 요약 | 결정 |
|---|---|---|---|---|---|
| `photo-verification-v1` | 과거 버전 | ID, 코드, 조건 유형, 설명, 필수 여부, 정렬 순서 | 최초 지침. 모호한 사진은 `UNCERTAIN`으로 보류 | 긍정 사진 18장, 조건 36개 중 최초 35개 `MET`; 부정 사례 없음 | 기록 보존 |
| `photo-verification-v2` | 기준선 | 조건 ID와 설명만 | 백엔드 입력에서 판정에 불필요한 필드를 제외 | 30장·60조건, 57/60 일치. 구미 오승인 1건 | 비교 기준선 |
| `photo-verification-v3` | 미채택 실험 | 조건 ID와 설명만 | 조건에 구체적으로 적힌 대상의 시각 증거를 요구하고 유사한 물건으로 대체하지 않도록 지시 | 영양제 2장 집중 평가에서 불투명 용기는 보류에서 `NOT_MET`으로 바뀌었지만 구미 오승인은 남음 | 미채택 |
| `photo-verification-v4` | 현재 기본값·검증 후보 | 조건 ID와 설명만 | v3 지침에 “구미 사탕은 정제나 캡슐이 아니다”라는 형태 구분 예시 추가 | v2와 같은 30장·60조건에서 58/60 일치, 오승인 0건, 오거절 1건 | 기본값으로 사용. 추가 검증 필요 |

현재 코드의 버전별 원문은 [`src/moamu_ai/prompts.py`](../../src/moamu_ai/prompts.py)의 `PROMPT_DEFINITIONS`에서 관리한다. 서비스 기본 버전은 `.env`의 `AI_PROMPT_VERSION`으로 선택하며 기본값은 v4다. 평가 명령은 `--prompt-version photo-verification-v2`처럼 지정할 수 있다. 새 버전은 기존 항목을 수정하지 않고 새 ID로 추가한다.

### 현재 평가 데이터셋

| 데이터셋명 | 버전 | 출처 | 이미지 / 도전 유형 | 조건 라벨 분포 | 분할 | 검수 | 매니페스트 | 이미지·출처 기록 | 한계 |
|---|---|---|---|---|---|---|---|---|---|
| 6개 도전 사진 판정 파일럿 | `2026-11-02` | Pexels | 30장 / 6개 유형, 유형별 5장 | 60개: `MET` 48, `NOT_MET` 12, `UNCERTAIN` 0 | `dev`만, 보류 세트 없음 | 단일 검수자 1명 | `data/evaluation/six-challenge-v2-pilot-20261102.jsonl` | 원본은 로컬 `AI_IMAGE_ROOT` 아래; 출처와 SHA-256은 [파일럿 보고서](six-category-v2-pilot-20261102.md)에 기록 | 유형별 부정 라벨이 2개뿐이고 독립 이중 검수 없음 |

평가 세트는 기존 긍정 사진 18장과 새 혼합 사례 12장으로 구성한다. 각 도전 유형은 사진 5장과 조건 라벨 10개이며, 그중 정답 부정 라벨은 유형별 2개다. 이 데이터는 프롬프트 오류를 찾는 개발용 파일럿이지 실제 사용자 사진 분포를 대표하는 보류 평가 세트가 아니다.

## Notion 표 연결 제안

- 모델 테스트 표의 `프롬프트 버전`은 프롬프트 표와 관계형으로 연결한다.
- 모델 테스트 표의 `평가 데이터셋`은 데이터셋 표와 관계형으로 연결한다.
- 프롬프트 표와 데이터셋 표에는 역방향 관계를 표시해 어떤 실행에 사용됐는지 조회한다.
- 이미지별 라벨을 따로 검토하려면 데이터셋의 매니페스트 JSONL을 가져와 사례별 하위 데이터베이스로 확장한다. 현재 초안은 세 개의 상위 표를 우선 구성한다.
