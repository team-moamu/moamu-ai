# Notion 모델·프롬프트 평가 기록 초안

Notion에는 네 개의 연결된 표를 둔다. **모델 카탈로그**는 모델 자체의 고정 정보를 관리하고, **모델 테스트**는 모델·프롬프트·데이터셋 조합으로 실행한 평가 기록을 관리한다. 프롬프트 버전과 평가 데이터셋은 각각 독립된 표로 유지한다.

현재 결과는 조건 단위의 개발 파일럿이다. 사진 제출 전체 승인율이나 PRD 성능 목표를 입증하지 않는다. 특히 2026-11-03 모델 비교는 양성 사진 6장만 쓴 초기 스크리닝이므로 오승인 성능을 비교하지 못한다.

## Notion 표 연결 제안

- 모델 테스트 표에서 모델 카탈로그, 프롬프트, 평가 데이터셋을 각각 관계형으로 연결한다. 모델 자체의 ID·가격·실행 방식은 모델 테스트 행에 중복 기록하지 않는다.
- 세 참조 표에는 모델 테스트 표의 역방향 관계를 추가해 각 모델·프롬프트·데이터셋 조합에서 나온 실행을 조회한다.
- 이미지별 라벨을 따로 검토하려면 매니페스트 JSONL을 가져와 사례별 하위 데이터베이스로 확장한다. 우선 네 개의 상위 표를 구성한다.
